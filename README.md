# U-Net-for-Biomedical-Image-Segmentation
• Implemented the U-Net encoder-decoder architecture with skip connections and contracting and expansive
paths for precise pixel-level biomedical image segmentation, localization, and structural boundary detection
• Built multi-scale feature extraction using convolution, max pooling, upsampling, and feature-map con-
catenation to preserve information during image reconstruction, segmentation and accurate pixel-level prediction
• Applied data augmentation and pixel-wise cross-entropy loss to improve segmentation robustness, boundary
localization, and generalization with limited annotated training images and complex cellular structures effectively
